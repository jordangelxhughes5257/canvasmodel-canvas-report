## What CanvasModel Does

CanvasModel runs in a web browser and helps users assemble a business model canvas before creating a matching report. It brings the model information into a structured workspace, making it easier to review the content and share the finished document.

The application is useful for founders, teams, students, consultants, and others who need a consistent process for working with a business model canvas. Its central workflow is turning canvas entries into a report that can be read, discussed, and presented.

---

## Capabilities

- Create a report from a business model canvas.
- Arrange business model details within a structured canvas.
- Turn completed canvas information into a report.
- Work through a browser-based interface.
- Check the canvas content before producing the final report.
- Provide a foundation for business model planning and discussion.
- Run as an HTML-based web application.
